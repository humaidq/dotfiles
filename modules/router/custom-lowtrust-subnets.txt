# Destination networks dropped LAN->WAN for devices in the low-trust pool only.
#
# Unlike custom-ip-blocklist.txt this file is meant to hold BLANKET entries —
# a /16 or wider where a provider is not worth enumerating host by host for a
# device that has no business there. That is only defensible because it applies
# to the pool rather than the house.
#
# One CIDR per line, v4 or v6, # comments. Parsed at build time.
#
# PREFIXES THE ASN EXPANSION CANNOT SEE, added 2026-08-13.
#
# custom-lowtrust-asns.txt turns AS numbers into ranges by reading
# ip2asn-combined.tsv, and that table is a static 43 MB file checked into this
# repo with no refresh mechanism. It is already out of date: fifty-four
# addresses in custom-throttle-list.txt sit in prefixes the table calls "not
# routed" while live BGP names an origin AS that is on the list. The expansion
# faithfully skips them, because it cannot know what the table does not say.
#
# Every prefix below was confirmed against live BGP (Team Cymru) and RIPE/ARIN
# whois, and each belongs to a provider already named in the ASN file. They are
# listed here rather than fixed at the source because refreshing the table is a
# separate job with its own risk; when it is refreshed these become redundant
# and can be deleted, which is why they are grouped and dated rather than
# scattered.
#
# The announced prefix is used rather than the narrower inetnum — same basis the
# ASN expansion works on, and it is the origin AS that makes the range the
# provider's.
