Full Reboot

Restarts the whole path in order: the fibre box first, then this router once the fibre is back, then every access point once the network has settled. Expect six to ten minutes with no internet, and no television or telephone while the fibre box is down.

If the fibre box does not come back the sequence stops there and leaves this router running, so there is still something to look at.
