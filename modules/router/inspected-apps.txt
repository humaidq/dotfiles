# Apps inspected for custom-blocklist.txt
#
# A record of every app whose backend was investigated, what came out of it,
# and — where nothing did — why. This file is documentation only; blocky reads
# custom-blocklist.txt and custom-whitelist.txt by explicit path and never
# looks here.
#
# Method, unless noted otherwise: fetch the package from APKPure, run
# .claude/skills/blocking-apps-by-domain/apk-domains.sh over it, verify every
# candidate against the router's resolver, then block the operator's zones as
# wildcards. Third-party SDK infrastructure (Agora, RongCloud, NetEase Yunxin,
# AppLovin, ironSource, Adjust, AppsFlyer, payment and ID-verification
# vendors) is deliberately left alone, since it is shared with unrelated apps.
#
# STATUS KEY
#   FULL     backend extracted from the package and verified
#   PARTIAL  package resisted extraction; some hosts recovered another way
#   BRAND    no usable extraction; blocked on operator/brand domains only
#   DNS      never unpacked; blocked on brand domains verified in DNS
#
# A BRAND or DNS entry is the weakest kind: it covers what the app advertises,
# not necessarily what it calls. If one of those apps still works, the blocky
# query log is the way to find what was missed.

                              IGFWProbeConfig, IBackupLbsConfig and
                              IDomainReplaceConfig. Static extraction and a

                              union. Runtime-only: bstream.kzhi.tech and
                              gdl.news-cdn.site. Static-only: imostatic.com (which
                              carries http-dns.imostatic.com, named in the native
                              libs), 19 CloudFront distributions, and the imodns/
                              lp2 mirror families on Azure, Fastly and Cloud Run.

                              Cloud SG addresses present in no DNS answer and no
                              string table — HTTPDNS returning raw IPs. Its
                              hardcoded 8.8.8.8 is already handled by the router's
                              LAN-to-WAN port 53 drop.

                              fronting allowlist inside the package matches

                              list is now a denylist, which is what makes the
