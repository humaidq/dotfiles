# Every HTTPDNS resolver, by name. These SDKs resolve over HTTP or HTTPS to a
# vendor endpoint, which bypasses blocky exactly as a DoH endpoint does, and
# every app family in this file that has one uses it to find the backends the
# entries above are meant to close: GOGO Live through Tencent's httpdns.gold,
# Gemgala through Baidu's httpdns.baidubce.com, SoulChill through Momo's
# httpdns.immomo.com. Those three stay listed individually above, with the
# evidence that found them; this generalises them to any vendor.
#
# The label is the giveaway and is safe to match on: a host with "httpdns" in
# a label is an HTTPDNS resolver, there being no legitimate use of the name.
# Matching the label rather than the zone catches both spellings in use —
# httpdns.<vendor>.com and intl.httpdns.<tld> — and any vendor not yet seen.
#
# What this cannot reach is an SDK that hardcodes the resolver's IP, which is
# the common case: Chatta calls Alibaba's HTTPDNS at 161.117.200.122 and
# 8.211.143.56 with no name involved. Those belong in custom-ip-blocklist.txt.
/(^|\.)[a-z0-9-]*httpdns[a-z0-9-]*\.[a-z0-9.-]+$/
